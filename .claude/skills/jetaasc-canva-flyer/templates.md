# Template pool

Vetted Canva templates for JETAASC flyers. `jetaasc-canva-flyer` picks from
here; `jetaasc-canva-template-scout` adds to it. Every entry is free (no
crown), single page, has no headshot slot, has text boxes wide enough to
take real event copy, and looks casual and Japan-flavoured rather than
corporate. Icon grids, "what to expect" rows, globe logos and networking
layouts do not belong here.

Editor link: navigating to it creates a fresh design from the template in
the current tab. Slots: the text boxes in reading order with their
placeholder text, so copy can be written to fit before opening Canva.
Character counts are placeholder lengths at the box's current width, not
hard limits: a box can usually be widened in the Arrange tab to the page
margins (7.5 in on an 8.5 in page) and then holds several times as much
at the same font size. Treat a count as "fits without any adjustment".

Update "Last used" when a flyer ships. Leave it blank for never.

Last scouted: 2026-09-17

The scout skill rewrites that date on every run. The flyer skill reads it
and says so when the pool is more than about four months stale.
